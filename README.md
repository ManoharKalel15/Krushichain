# 🌾 KrushiChain – Maharashtra District Pilot App
## React Web + Node.js + MongoDB Atlas | 100 Farmers Ready

## 🚀 Quick Start (3 Steps)

### Step 1 – MongoDB Atlas
1. cloud.mongodb.com → Free account → New Cluster (Mumbai)
2. Network: Allow 0.0.0.0/0
3. Connection string copy करा

### Step 2 – Backend
```bash
cd backend
cp .env.example .env     # MONGO_URI टाका
npm install
npm run dev              # http://localhost:5000
```

### Step 3 – Frontend
```bash
cd frontend
npm install
npm run dev              # http://localhost:5173
```
